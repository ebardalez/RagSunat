# Habilidad: normas de la SUNAT

Esta habilidad NO contiene normas ni datos vigentes: contiene el marco para interpretarlas. Los hechos concretos (plazos, montos, artículos)
salen siempre de los fragmentos recuperados con la herramienta de búsqueda y se citan como [n].

## Cuándo usarla
- El usuario pregunta "¿qué es / qué valor tiene este documento?" (resolución de superintendencia, informe, proyecto de resolución).
- Necesitas ubicar dónde está la respuesta dentro de una resolución (considerandos, artículos, disposiciones finales, anexos).
- La pregunta del usuario es coloquial y la búsqueda no devuelve nada útil: necesitas el vocabulario normativo equivalente.

## Referencias (léelas solo si las necesitas)
- `references/tipos-de-normas.md`: jerarquía y tipos de documentos, y qué valor tiene cada uno.
- `references/como-leer-una-resolucion.md`: anatomía de una resolución de superintendencia y dónde buscar plazos, ámbito y vigencia.
- `references/vocabulario-tributario.md`: traducción de lenguaje coloquial a términos normativos, para reformular consultas.

## Reglas de uso
1. Esta habilidad explica CÓMO leer; no la cites como fuente de una norma. Cita solo fragmentos recuperados.
2. Si una referencia y un fragmento recuperado se contradicen, manda el fragmento.
3. El índice cubre solo documentos de 2025: avisa que la vigencia debe verificarse en fuentes oficiales.
